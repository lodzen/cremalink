cremalink.ecam.monitor_bits module

Monitor frame bit tables — the machine’s switch and alarm words.

Names come from the official enums in Coffee Link 4.9.6 (m6.p for switches, m6.l for alarms); see research/protocol.md Registers 4.1 and 4.2. Values are the raw bit states — whether a set bit means “fault” or “present” is given by each label.

The switches word is 2 bytes (bit n = switches[n // 8] >> n % 8); the alarms word is 4 bytes assembled from non-contiguous payload bytes by MonitorFrame.

Alarm bits. Bits 0, 1 and 13 (water tank empty / waste container full / tank in position) are exposed by the dedicated is_watertank_* and is_waste_container_full flags. Bits 28-31 are unmapped.
